# Color Feast Drop prototype v0.9 — Forest UI

v0.8 のルールは維持したまま、スマホ画面の見栄えを大幅に更新した版です。

- 森・木枠をモチーフにした盤面
- 丸い実と房の枝表現
- 紫はトゲ付きの硬い殻
- 紫喰いを常時UIに登場させ、残り5房以下でソワソワ、2房以下で強く警告
- 「あと16房」をキャラクターと一体化して表示
- 16房ごとに紫喰いが盤面を横切って紫を全捕食
- 捕食後のみセル単位重力、その後通常色3個以上の連鎖

GitHub Pages ではリポジトリ直下に `index.html`, `style.css`, `game.js` を置けば動作します。
