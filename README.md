# Color Feast Drop — prototype v0.1

「次に食べられる色」を利用して連鎖を仕込む落ちゲーの検証版です。

## ルール
- 8×16盤面、4色（緑・紫・オレンジ・シアン）
- 4マスのピースが落下し、各セルの色は個別にランダム
- 通常色は上下左右に3個以上つながると消える
- NEXT FEAST の対象色だけは、何個つながっても通常消去されない
- ピースを置くたびにカウントダウン
- 0になると対象色を盤面から一斉に捕食（全消去）
- その後セル単位で落下し、通常色の3個消し→落下→再判定で連鎖
- 捕食後は別の対象色に切り替わる

## 操作
- ← / → : 移動
- ↓ : ソフトドロップ
- Z : 左回転
- X / ↑ : 右回転
- Space : ハードドロップ
