# Color Enclose Drop v0.5

落下する色付きピースで「別の色を囲む」ルールを検証するプロトタイプです。

## 現在のルール
- 盤面: 8 x 16
- 通常色: 緑・紫・オレンジ
- 約8%でオールカラーピース
- 1〜4マスのピース
- 横一列完成では消えません
- 左右接続ルールは削除しました
- 同じ色の連結した塊が、別の色のブロックを完全に囲むと「囲んだ側」だけ消えます
- 囲われた内側のブロックは残ります
- 空白だけを囲っても消えません
- 囲みは上下左右のつながりで判定します
- オールカラーはどの色の囲みにも使え、成立した囲みと一緒に消えます
- 消去後はセル単位で下に落下し、新しい囲みができれば連鎖します
- 着地済みの同色ブロック同士は境目を消し、一つの塊に見える表示です
- NEXT 3個、HOLDなし

## 操作
- ← →: 移動
- ↓: 1段落下
- Z: 左回転
- X / ↑: 右回転
- Space: ハードドロップ
- スマホ: 左側に方向操作、右側に左回転・右回転

## 実行
`index.html` をブラウザで開くだけです。GitHub Pagesでもそのまま公開できます。
