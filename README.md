# Color Enclose Drop v0.7

落下する色ブロックで別色を囲み、囲んだ側の色だけを消す実験用プロトタイプです。

## v0.7
- 壁判定を修正。
- 同色の連結塊が左壁・右壁・床の同じ辺に2点以上触れると、その接点間の壁がその色になり、囲みの一辺として機能します。
- 有効になった壁区間は盤面上で色付き表示されます。
- 天井は囲みに使えません。
- 方向ボタンを `←   →` の下中央に `↓` が来る配置へ変更しました。
- 左右接続・横一列消去はありません。

`index.html` をブラウザで開けば遊べます。GitHub Pagesにもそのまま配置できます。
