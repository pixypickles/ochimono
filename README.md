# Color Enclose Drop v0.8

落下する色ブロックで別色を囲み、囲んだ側の色だけを消す実験用プロトタイプです。

## v0.8
- ピースを **2・3・4・5マスの直線ブロックのみ** に変更。
- 出現率は 2マス 30% / 3マス 30% / 4マス 25% / 5マス 15%。
- 回転で横棒・縦棒を切り替えられます。
- 緑・紫・オレンジの3色＋低確率のオールカラーは継続。
- 左右壁・床を囲みに利用できる v0.7 のルールは継続。天井は使えません。
- 左右接続・横一列消去はありません。

`index.html` をブラウザで開けば遊べます。GitHub Pagesにもそのまま配置できます。
