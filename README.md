# Color Enclose Drop v0.6

落ちてくる同色ブロックで別の色を囲み、囲んだ側を消すルールの試作です。

## v0.6
- 左右接続ルールなし
- 同色で別色を囲むと、囲んだ色だけ消去（中身は残る）
- 左右の壁と床は、接しているロック済みブロックの色として囲み判定に利用
- 天井は囲みには使えない
- 同色のロック済みブロック同士は境界線なしで一つの塊に見える
- 通常色は緑・紫・オレンジ、低確率でオールカラー
- 左側に方向キー、右側に左右回転
- DROPボタンを方向キーから離して右側上部へ移動
- 消去後はセル単位で落下し、再び囲みができれば連鎖

`index.html` をブラウザで開けば遊べます。GitHub Pagesでもそのまま公開できます。
